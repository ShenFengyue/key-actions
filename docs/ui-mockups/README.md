# UI 方向稿（两版对比）

两份都是**方向稿**，不是最终实现：用 1560×980（真实窗口尺寸）和真实内容画的静态稿，
内容完全相同，只对比「导航形态 + 信息层级」。看图：

- `a-editorial.png` — A：纸面极简（文字导航、无卡片框、留白分组）
- `b-rail.png` — B：图标轨仪表盘（56px 图标轨、卡片分层、密度更高）

源码为同名 `.html`，改完用 Chrome 重新出图即可：

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu `
  --hide-scrollbars --force-device-scale-factor=1 --window-size=1560,980 `
  --screenshot="docs\ui-mockups\a-editorial.png" "file:///<绝对路径>/a-editorial.html"
```

## 两版共同的改动（相对当前 v1.42 界面）

1. 侧栏不再是一列 44px 的白底描边大按钮，导航变成 32px 的文字/图标项。
2. 页面标题从 15px 提到 20px（A）或 16px（B），并配一句状态副标题。
3. 蓝色只留给「主操作 + 当前页」；状态（进行中）降为淡色标签，不再和按钮抢。
4. 热力图只保留一条时间轴：领域图不再各自重复 12 个月份标签。
5. 领域图从「每节点一整张日历、竖向狂滚」变成一行两个、格子小一号。
6. 新增「今天」区块，收掉原来总览底部的空白。
7. 数字统一等宽（tabular-nums），时钟不再和正文混排。

## A · 纸面极简

- 结构：白底、只有一条 1px 竖线分隔侧栏；区块之间靠 32px 留白分，不画卡片框。
- 当前重点：三栏 + 竖细线分隔，不是三张卡片。
- 快速记录：无边框、下划线式字段，一行读完。
- 气质：像一份排得好的纸面文档；适合「一次只推进一件事」的极简取向。
- 代价：无框设计容错低，任何一处对齐错 2px 都会很显眼；后续加新模块要守间距规范。

## B · 图标轨仪表盘

- 结构：58px 图标轨（无文字，靠图标 + tooltip），主区浅灰底 + 白卡片 + 10px 圆角。
- 右侧「669 总记录 / 176 活跃天」做成 KPI，时钟并进同一列。
- 气质：更像一个"应用"，密度更高，窗口拉宽时更好看。
- 代价：图标轨要新做 9 个图标；纯图标牺牲可发现性，第一次用要猜；卡片多一层描边，页面更"重"。

## 建议

- 如果目标是**耐看的个人工具**：选 A。改动集中 `theme.py` + `widgets/sidebar.py` + `common.py`，
  不动页面结构，1.5 天左右能落地。
- 如果目标是**塞得下更多信息、窗口常驻最大化**：选 B，但要额外做图标资源和 tooltip。
- 两版都还没画深色版；定方向后先补深色对照，再动代码。
